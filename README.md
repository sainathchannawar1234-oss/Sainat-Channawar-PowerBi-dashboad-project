# PowerBi- Clothing Buisness Bnalysis
Developed an interactive Power BI dashboard for Fashion Product Sales Analysis using real-world sales data containing 1000+ records. The dashboard was designed to analyze sales performance, customer behavior, profitability, and regional trends to support business decision-making.
1)Created interactive dashboards with KPI cards for Total Sales, Profit, Revenue, Orders, Customers, and Profit Margin', ASP(average sales Price)
2)Performed data cleaning, transformation, and modeling using Power Query and DAX
3) Developed dynamic visualizations including trend analysis, regional analysis, product performance, order status, and customer insights.
4) Implemented slicers, filters, drill-down analysis, and cross-functional reports for better user interaction.
5) Analyzed sales trends by year, quarter, month, region, brand, and sub-category to identify business growth opportunities.
6) Tools Used: Power BI, SQL, CSV, DAX, Power Query
